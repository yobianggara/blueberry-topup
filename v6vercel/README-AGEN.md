# V20 - Registrasi Agen (Harga Lebih Murah)

## Yang DIHAPUS
- Registrasi ke raffmong@gmail.com -> DIHAPUS TOTAL
- Notif lonceng / bell -> DIHAPUS TOTAL
- Registrasi web lama -> DIHAPUS

## Yang BARU
- Tombol: Daftar Jadi Agen - Harga Lebih Murah
- Form: Nama, WA, Email, Kota, Mau jualan apa
- Submit -> data tersimpan di Admin (Registrasi Agen) + WA owner (088802561769) kebuka otomatis dengan pesan lengkap
- Owner Approve di Admin -> WA / email pendaftar untuk konfirmasi
- Sukses pendaftar dari WA owner / email yang mereka daftarkan, bukan lonceng

## Transaksi Agen - BISA
- Agen yang sudah Approve -> order seperti biasa (Top Up / Voucher)
- Order agen masuk ke Laporan Harian / Bulanan di Admin seperti order biasa
- Bedanya: harga agen lebih murah (atur di Harga Manual Admin: set harga agen per produk, atau beri diskon manual saat rekap)
- Untuk V20 ini, harga agen diaktifkan via Approve + konfirmasi WA. Harga agen per produk diatur di menu Harga (Edit Manual) - beri harga khusus untuk agen.
